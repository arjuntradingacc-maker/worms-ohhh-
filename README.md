# MATCH THE LIQUID

**Pour it. Match it. Pop it!**

Match the Liquid is an original candy-colored liquid-sorting puzzle game.
Tap a container to pick it up, tap another to pour — sort every color into
its own container to clear the level. It's built from scratch with its own
identity: seven original container silhouettes (no generic test tubes), an
original mascot (**Liqi**, a small liquid blob), a fully synthesized sound
library (no audio files), and a funky squash-and-stretch animation system
covering every interaction.

This repo is a **complete, playable client**: pure HTML/CSS/JS, no build
step, no external binary assets (all art is drawn on `<canvas>`, all audio
is synthesized with the Web Audio API). Open `index.html` through a local
server and it runs.

## Running it

```
npm run dev
```

then open `http://localhost:8080` on your phone or desktop browser. (Any
static file server works — `npx serve`, `python3 -m http.server`, etc. — a
server is required because the game loads ES modules, which browsers block
over `file://`.)

## How to play

- **Select**: tap a container with liquid in it.
- **Pour**: tap a different container. The pour succeeds if that container
  is empty, or its top color matches what you're pouring.
- **Undo / Reset**: available any time from the in-game controls.
- Sort every color into a single container, filled to the top, to clear
  the level. Fewer moves earns more stars (and more coins).

40 levels across 5 worlds (Candy, Neon, Space, Jungle, Endgame), each with
its own palette, container shapes and generative music track. Beating a
world's final level unlocks a cosmetic "Liquid FX" flavor in the
collection screen (Jelly, Neon, Glitter, Soda, Galaxy, Lava, Rainbow,
Bubble, Crystal, Electric) — purely visual flourishes layered onto that
world's boss-level liquid.

## What's real vs. what's simulated

Being upfront about the seam between "runs entirely in your browser" and
"would need a real backend to ship":

**Fully implemented, running live in this build:**
- The full puzzle engine (`src/game/engine.js`) and all 40 levels
  (`src/game/level-data.js`), each generated by randomly dealing colors
  into containers and *verified solvable* offline by a weighted-A* solver
  (`tools/precompute-levels.mjs`) — every level ships with a real
  optimal-ish "par" move count used for star ratings, not a guess.
- The full animation system: container select/pour/perfect-match/invalid-
  move/level-complete choreography, a living wavy liquid surface, rising
  bubbles, pour-stream droplets, confetti, star spirals, and screen shake —
  all hand-built on a small tween engine (`src/core/utils.js`), no
  animation library.
- Liqi, an original mascot with a full state machine (idle/blink/excited/
  dancing/asleep/celebrating/confused/jumping), drawn procedurally.
- A completely original synthesized sound library (`src/core/audio.js`):
  layered oscillator/noise SFX for pour/match/perfect/invalid/button/
  select/level-complete/coins, pitch-shifted pour sound by liquid color,
  and a reactive combo system (escalating musical phrases at high combo).
- Five generative background music tracks (one per world), built on a
  drift-free lookahead scheduler, that get busier as your combo rises.
- Progression: coins, per-level stars, world unlocks, a cosmetic FX
  collection — all persisted to `localStorage`.
- Accessibility: color-blind pattern glyphs, high-contrast mode, reduced-
  motion mode, and independent sound/music/haptics toggles — colors are
  never the only way to tell liquids apart.
- Haptic feedback via the Vibration API (with a settings toggle), and a
  mobile-first responsive canvas layout with safe-area insets.

**Simulated / stubbed, by necessity:**
- **No backend.** Coins, stars and settings live in `localStorage` on one
  device — there's no account system, cloud sync, or leaderboard service,
  because this is a static client repo with nowhere to run one. Nothing in
  the UI claims otherwise.
- **App icon** ships as an SVG (`public/icon.svg`) designed to the brief
  (original bottle silhouette, layered liquid splash, glossy 3D look, no
  text) rather than as platform-specific rasterized icon sets, since
  producing `.ico`/`.icns`/Android adaptive-icon bundles needs a native
  packaging step this repo doesn't include.
- **Packaging as an actual mobile app** (App Store / Play Store) would
  need wrapping this web client in something like Capacitor or a WebView
  shell and going through store submission — outside what a static HTML/
  CSS/JS repo can do on its own. The gameplay itself is written mobile-
  first (touch input, safe-area insets, portrait canvas layout) so that
  wrapping step would be mechanical, not a rewrite.

## Architecture

```
index.html              Screen DOM skeletons; content is filled in by JS.
styles/main.css          The whole bouncy/glossy design system, CSS variables for theming.
src/
  core/                  Framework-free utilities: tween engine + easing, save/settings,
                         particle system, haptics, the synthesized audio engine.
  game/                  Pure simulation, no DOM/canvas:
                         engine.js (pour rules), levels.js + level-data.js (the 40 levels),
                         session.js (wires engine -> renderer -> audio -> combo).
  render/                containers.js (7 original container shapes), mascot.js (Liqi),
                         renderer.js (the gameplay Scene: layout, liquid, every animation).
  input/pointer.js        Pointer-events tap-to-container-index mapping.
  ui/screens.js           DOM screen navigation, level grid, settings, collection, HUD.
  main.js                 Wires everything together and runs the game loop.
tools/precompute-levels.mjs   Offline generator + solver that produced level-data.js.
server.js                Zero-dependency static file server for local dev.
```

The simulation (`src/game/engine.js`) never touches the DOM or canvas, and
the renderer never mutates simulation state — `session.js` is the only
place that reads an engine result and tells the renderer what to animate.

## Design notes

- **Original container shapes, not test tubes.** Bubble bottles, jelly
  jars, squishy tubes, candy containers, capsule bottles, funky potion
  jars and rounded soda bottles — each world uses a different pair so the
  same puzzle mechanic keeps feeling fresh.
- **Levels are honestly solvable.** Rather than a runtime generator (which
  either risks unsolvable puzzles or needs a slow in-browser solver), all
  40 layouts are precomputed and verified once; the shipped game does zero
  search at runtime and always has a known par for star ratings.
- **Mistakes are funny, not punishing.** An invalid pour doesn't buzz or
  flash red — the container wobbles, gets a tiny cartoon face for a beat,
  and the combo resets quietly. There's no time pressure, so thinking
  before a move never costs anything.
